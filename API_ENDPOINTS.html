🌟 HadeethEnc Compatible EndpointsPOPULAR

GET /api/hadeeths/one COMPLETE
Get a single hadith with complete metadata (references, hints, explanations, narrator intro)
📌 Examples:
http://127.0.0.1:8000/api/hadeeths/one?id=75455&language=bn http://127.0.0.1:8000/api/hadeeths/one?id=75614&language=en http://127.0.0.1:8000/api/hadeeths/one?id=1690&language=ar
GET /api/hadeeths/list
List hadiths by category with pagination
📌 Examples:
http://127.0.0.1:8000/api/hadeeths/list?language=bn&category_id=1&page=1&per_page=20 http://127.0.0.1:8000/api/hadeeths/list?language=en&category_id=3&page=1&per_page=10
GET /api/categories/roots
Get root categories (top-level categories) in specified language
📌 Examples:
http://127.0.0.1:8000/api/categories/roots?language=bn http://127.0.0.1:8000/api/categories/roots?language=en http://127.0.0.1:8000/api/categories/roots?language=ar
GET /api/languages
Get list of all supported languages with ISO codes
📌 Example:
http://127.0.0.1:8000/api/languages

📚 Categories Endpoints

GET /api/categories
Get all categories with localized names
📌 Examples:
http://127.0.0.1:8000/api/categories?language=bn http://127.0.0.1:8000/api/categories?language=en
GET /api/categories/{id}
Get specific category details with hadith count and subcategories
📌 Examples:
http://127.0.0.1:8000/api/categories/1?language=bn http://127.0.0.1:8000/api/categories/3?language=en
GET /api/categories/{id}/hadeeths
Get all hadiths belonging to a category (paginated)
📌 Examples:
http://127.0.0.1:8000/api/categories/1/hadeeths http://127.0.0.1:8000/api/categories/5/hadeeths

📖 Books Endpoints

GET /api/books
Get all hadith books (collections) with chapters
📌 Example:
http://127.0.0.1:8000/api/books
GET /api/books/{id}
Get specific book by ID, code, or slug
📌 Examples:
http://127.0.0.1:8000/api/books/1 http://127.0.0.1:8000/api/books/sahih-bukhari
GET /api/books/{book}/chapters
Get all chapters for a specific book
📌 Examples:
http://127.0.0.1:8000/api/books/1/chapters http://127.0.0.1:8000/api/books/sahih-bukhari/chapters
GET /api/books/{book}/chapters/{chapter}/hadeeths
Get hadiths from a specific chapter in a book
📌 Examples:
http://127.0.0.1:8000/api/books/1/chapters/1/hadeeths http://127.0.0.1:8000/api/books/sahih-bukhari/chapters/5/hadeeths
GET /api/books/{book}/hadeeths/{number}
Get specific hadith by book and hadith number
📌 Examples:
http://127.0.0.1:8000/api/books/1/hadeeths/1 http://127.0.0.1:8000/api/books/sahih-bukhari/hadeeths/25
GET /api/books/{book}/hadeeths/{number}/translations/{lang}
Get hadith translation in specific language
📌 Examples:
http://127.0.0.1:8000/api/books/1/hadeeths/1/translations/bn http://127.0.0.1:8000/api/books/1/hadeeths/25/translations/en

🔍 Search & Random Endpoints

GET /api/search/{term}

📌 Examples:
http://127.0.0.1:8000/api/search/prayer http://127.0.0.1:8000/api/search/صلاة
