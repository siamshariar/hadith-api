📚 Hadith API Documentation

Comprehensive REST API for accessing Islamic Hadith collections with multiple translations and categories.

📊 Database Statistics

  • 7 Books - Complete collections from major Hadith scholars
  • 411 Hadiths - Total hadiths across all books
  • 4 Languages - Bengali (BN), English (EN), Turkish (TR), Urdu (UR)
  • 2,320 Categories - Comprehensive categorization system

🏗️ API Structure

The API follows a hierarchical structure: Books → Chapters → Hadiths → Translations

💡 Tip: All endpoints return JSON responses with consistent structure including success, data, and meta fields.

📋 Core Endpoints

📚 Books

GET /api/books
Description: Get all books with their chapters
Response: Array of books with nested chapters
GET /api/books/{book}
Description: Get specific book details
Parameters: book - Book ID, code, or slug (e.g., 1, bukhari, sahih-al-bukhari)
Response: Single book object
GET /api/books/{book}/chapters
Description: Get all chapters for a specific book
Parameters: book - Book ID, code, or slug
Response: Array of chapters with fields: id, chapter_no, name_en, name_ar, total_hadith

📖 Hadiths

GET /api/books/{book}/chapters/{chapter}
Description: Get hadiths for a specific chapter (paginated)
Parameters: book - Book ID/code/slug, chapter - Chapter number
Response: Paginated hadiths with book and chapter relationships
GET /api/hadiths/{id}
Description: Get specific hadith by database ID
Parameters: id - Hadith database ID
Response: Single hadith with book and chapter details
GET /api/books/{book}/hadiths/{hadith_number}
Description: Get specific hadith by book and hadith number
Parameters: book - Book ID/code/slug, hadith_number - Hadith number within the book
Response: Single hadith object

🌍 Translations

GET /api/books/{book}/hadiths/{hadith_number}/translations/{lang}
Description: Get translation for a specific hadith
Parameters: book - Book ID/code/slug, hadith_number - Hadith number, lang - Language code (en, bn, tr, ur)
Response: Hadith with translation object
GET /api/hadiths/{id}/translations/{lang}
Description: Get translation for hadith by database ID
Parameters: id - Hadith database ID, lang - Language code
Response: Hadith with translation object

🔍 Search & Discovery

GET /api/search/{term}
Description: Search hadiths by Arabic text or translation
Parameters: term - Search term
Response: Array of matching hadiths (max 50 results)
GET /api/random
Description: Get a random hadith
Response: Single random hadith with book and chapter details

🏷️ Categories

GET /api/categories
Description: Get all categories
Response: Array of all categories with hierarchical structure
GET /api/categories/{category}/hadiths
Description: Get hadiths for a specific category (paginated)
Parameters: category - Category ID
Response: Paginated hadiths belonging to the category
