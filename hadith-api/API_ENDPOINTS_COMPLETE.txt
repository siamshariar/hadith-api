GET  /api/categories
     → List all categories
     Parameters:
       - language={code}        (e.g., en, ar, bn, ru)
     Example: /api/categories?language=en

GET  /api/categories/list
     → Alias for /api/categories

GET  /api/categories/roots
     → Get root/parent categories only
     Parameters:
       - language={code}
     Example: /api/categories/roots?language=en

GET  /api/categories/{id}
     → Get specific category with details
     Parameters:
       - language={code}
       - include_hadiths={true/false}
       - limit={number}          (default: 10)
     Example: /api/categories/3?language=en&include_hadiths=true&limit=5
     
     ✨ NEW: Now includes language-specific number localization!
       - Bengali (bn): ৪৪৯৭ instead of 4497
       - Arabic (ar): ٤٤٩٧ instead of 4497
       - English (en): 4497 (Western numerals)

GET  /api/categories/{id}/children
     → Get subcategories of a category
     Parameters:
       - language={code}
     Example: /api/categories/3/children?language=en

GET  /api/categories/{id}/hadiths
GET  /api/categories/{id}/hadeeths (alias)
     → Get hadiths in a specific category
     Parameters:
       - language={code}
       - limit={number}
       - offset={number}
     Example: /api/categories/3/hadiths?language=en&limit=20

GET  /api/books
     → List all books
     Parameters:
       - language={code}
     Example: /api/books?language=en

GET  /api/books/{book}
     → Get specific book details
     Parameters:
       - language={code}
     Example: /api/books/bukhari?language=en

GET  /api/books/{book}/chapters
     → Get all chapters in a book
     Parameters:
       - language={code}
     Example: /api/books/bukhari/chapters?language=en

GET  /api/books/{book}/chapters/{chapter}
     → Get hadiths in a specific chapter
     Parameters:
       - language={code}
       - limit={number}
       - offset={number}
     Example: /api/books/bukhari/chapters/1?language=en&limit=10

GET  /api/books/{book}/hadiths/{hadith_number}
GET  /api/books/{book}/hadeeths/{hadith_number} (alias)
     → Get specific hadith by book and hadith number (any chapter)
     Parameters:
       - language={code}
     Example: /api/books/muslim/hadiths/92?language=en

GET  /api/books/{book}/hadeeths/{hadith_number}/translations/{lang} (alias)

     Example: /api/books/bukhari/hadiths/4497/translations/bn

{
  "success": true,
  "data": {
    // Response data here
  }
}

Or on error:

{
  "success": false,
  "error": "Error message",
  "message": "Detailed error description"
}


╔══════════════════════════════════════════════════════════════════════════════╗
║                           COMMON PARAMETERS                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

language={code}        - Language code (en, ar, bn, ru, etc.)
                         ✨ Numbers are automatically localized!

limit={number}         - Number of results to return (default varies)
offset={number}        - Pagination offset
include_hadiths={bool} - Include hadith data in response (for categories)


╔══════════════════════════════════════════════════════════════════════════════╗
║                           EXAMPLE USAGE                                      ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Get categories in Bengali with hadiths and localized numbers:
   GET /api/categories/3?language=bn&include_hadiths=true&limit=1
   → Returns: বুখারীঃ৪৪৯৭ ও মুসলিমঃ৯২

2. Get categories in English with references:
   GET /api/categories/3?language=en&include_hadiths=true&limit=1
   → Returns: Sahih al-Bukhari (6/ 23) (4497)

3. Get categories in Arabic with Arabic numerals:
   GET /api/categories/3?language=ar&include_hadiths=true&limit=1
   → Returns: صحيح البخاري (٦/ ٢٣) (٤٤٩٧)

4. Search for hadiths about prayer:
   GET /api/search?q=prayer&language=en&limit=10

5. Get a random hadith:
   GET /api/random?language=en

6. Get specific book chapters:
   GET /api/books/bukhari/chapters?language=en


╔══════════════════════════════════════════════════════════════════════════════╗
║                           NEW FEATURES                                       ║
╚══════════════════════════════════════════════════════════════════════════════╝

✨ Language-wise Number Localization
   - Automatic conversion of numbers to language-specific numerals
   - Bengali: ৪৪৯৭ instead of 4497
   - Arabic: ٤٤٩٧ instead of 4497
   - Hindi: ४४९७ instead of 4497
   - Persian/Urdu: ۴۴۹۷ instead of 4497

✨ Reference Translation Support
   - Hadith references now display in all languages
   - Clean references for Bengali (embedded in translation)
   - Arabic references for English/Russian (fallback for corrupted data)
   - Numbers in references are localized per language

✨ Smart Corruption Detection
   - Automatically detects and filters out garbled reference data
   - Falls back to clean Arabic references when needed
   - Prevents duplication of references
