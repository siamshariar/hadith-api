📚 Hadith API Documentation

Complete API Reference with Live Examples & Number Localization

Base URL: http://127.0.0.1:8000/api

✨ New Features

  • Language-wise Number Localization - Automatic conversion to Bengali (৪৪৯৭), Arabic (٤٤٩٧), Hindi (४४९७) numerals
  • Reference Translation Support - Hadith references display in all languages with proper number formatting
  • Smart Corruption Detection - Automatically filters garbled data and provides clean Arabic fallback
  • UTF-8 Unicode Support - Full support for all languages with proper character encoding

📚 Category Endpoints

GET /api/categories

List all categories in specified language

Parameters:

language - Language code (en, ar, bn, ru, etc.)
Example - English:
http://127.0.0.1:8000/api/categories?language=en
GET /api/categories/{id} NEW FEATURE

Get specific category with hadiths (includes number localization!)

Parameters:

language - Language code (en, ar, bn, etc.)
include_hadiths - true/false (include hadith data)
limit - Number of hadiths to return (default: 10)
Example - Bengali with localized numbers (৪৪৯৭, ৯২):
http://127.0.0.1:8000/api/categories/3?language=bn&include_hadiths=true&limit=1
Example - English with Western numbers (4497, 92):
http://127.0.0.1:8000/api/categories/3?language=en&include_hadiths=true&limit=1
Example - Arabic with Arabic numbers (٤٤٩٧, ٩٢):
http://127.0.0.1:8000/api/categories/3?language=ar&include_hadiths=true&limit=1
GET /api/categories/roots

Get only root/parent categories

Parameters:

language - Language code
Example:
http://127.0.0.1:8000/api/categories/roots?language=en
GET /api/categories/{id}/children

Get subcategories of a specific category

Parameters:

language - Language code
Example:
http://127.0.0.1:8000/api/categories/3/children?language=en
GET /api/categories/{id}/hadiths

Get hadiths in a specific category

Parameters:

language - Language code
limit - Number of results (default: 10)
offset - Pagination offset
Example:
http://127.0.0.1:8000/api/categories/3/hadiths?language=en&limit=5

📖 Book Endpoints

GET /api/books

List all hadith books

Parameters:

language - Language code
Example:
http://127.0.0.1:8000/api/books?language=en
GET /api/books/{book}

Get specific book details by code

Parameters:

language - Language code
Example - Get Sahih Bukhari:
http://127.0.0.1:8000/api/books/bukhari?language=en
GET /api/books/{book}/chapters

Get all chapters in a book

Parameters:

language - Language code
Example:
http://127.0.0.1:8000/api/books/bukhari/chapters?language=en
GET /api/books/{book}/chapters/{chapter}

Get hadiths in a specific chapter

Parameters:

language - Language code
limit - Number of results
offset - Pagination offset
Example:
http://127.0.0.1:8000/api/books/bukhari/chapters/1?language=en&limit=3
GET /api/books/{book}/hadiths/{number}

Get specific hadith by book code and hadith number

Parameters:

language - Language code
Example - Get Bukhari Hadith #4497:
http://127.0.0.1:8000/api/books/bukhari/hadiths/4497?language=en

📜 Hadith Endpoints

GET /api/hadiths

Query and filter hadiths

Parameters:

language - Language code
book_id - Filter by book ID
chapter_id - Filter by chapter ID
category_id - Filter by category ID
grade - Filter by grade (صحيح, حسن, etc.)
limit - Number of results
offset - Pagination offset
Example - Sahih hadiths:
http://127.0.0.1:8000/api/hadiths?language=en&grade=صحيح&limit=5
GET /api/hadiths/{id} LOCALIZED

Get specific hadith by ID (with number localization)

Parameters:

language - Language code
Example - Bengali (৪৪৯৭):
http://127.0.0.1:8000/api/hadiths/75963?language=bn
Example - English (4497):
http://127.0.0.1:8000/api/hadiths/75963?language=en
GET /api/hadeeths/one

Get one specific or random hadith (HadeethEnc compatible)

Parameters:

language - Language code
id - Hadith ID (optional, random if not provided)
Example - Specific hadith:
http://127.0.0.1:8000/api/hadeeths/one?language=en&id=75963
GET /api/hadeeths/list

List hadiths (HadeethEnc compatible endpoint)

Parameters:

language - Language code
limit - Number of results
Example:
http://127.0.0.1:8000/api/hadeeths/list?language=en&limit=3

🔍 Search Endpoints

GET /api/search

Full-text search across hadiths

Parameters:

q - Search query (required)
language - Language code
book_id - Filter by book
category_id - Filter by category
limit - Number of results
offset - Pagination offset
Example - Search for "prayer":
http://127.0.0.1:8000/api/search?q=prayer&language=en&limit=5
Example - Search in Bengali "আল্লাহ":
http://127.0.0.1:8000/api/search?q=আল্লাহ&language=bn&limit=3
GET /api/search/{term}

Search with term in URL path

Parameters:

language - Language code
limit - Number of results
Example:
http://127.0.0.1:8000/api/search/faith?language=en&limit=5
