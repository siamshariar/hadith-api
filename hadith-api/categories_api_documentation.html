🏷️ Categories API Documentation

Comprehensive REST API for accessing Hadith categories with hierarchical organization and hadith listings.

📊 Categories Statistics

  • 2,320 Categories - Comprehensive categorization system
  • Hierarchical Structure - Parent-child category relationships
  • Cross-linked - Categories connected to hadiths via many-to-many relationships
  • Multi-language - English and Arabic category names

📂 Categories Hierarchy Structure

🏷️ Categories → 📖 Hadiths → 🌍 Translations

Similar to Books structure but organized by topics/themes

📋 Categories API Endpoints

🏠 Categories Home Page

GET /api/categories
Description: Get all categories with hierarchical structure
Response: Array of all categories with parent-child relationships
GET /api/categories/{category}
Description: Get specific category details with subcategories and hadith count
Parameters: category - Category ID
Response: Single category with subcategories and statistics

📖 Category Hadiths

GET /api/categories/{category}/hadiths
Description: Get hadiths for a specific category (paginated)
Parameters: category - Category ID
Response: Paginated hadiths belonging to the category with book and chapter details

🌍 Hadith Translations (Same as Books)

GET /api/hadiths/{id}/translations/{lang}
Description: Get translation for hadith by database ID
Parameters: id - Hadith database ID, lang - Language code (en, bn, tr, ur)
Response: Hadith with translation object
GET /api/books/{book}/hadiths/{hadith_number}/translations/{lang}
Description: Get translation for hadith by book and hadith number
Parameters: book - Book ID/code/slug, hadith_number - Hadith number, lang - Language code
Response: Hadith with translation object

📊 Categories vs Books Comparison

🛠️ Implementation Notes

✅ Categories API Features:
- Hierarchical category structure with parent-child relationships
- Many-to-many relationship between categories and hadiths
- Pagination support for large category hadith lists
- Consistent JSON response structure matching Books API
- Subcategory information included in category details
🔧 Database Relationships:
- categories table with parent_id for hierarchy
- hadith_category pivot table for many-to-many relationships
- Categories can have multiple hadiths, hadiths can belong to multiple categories
- Translations work identically to Books API (same endpoints)
