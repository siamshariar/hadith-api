🌟 HadeethEnc Compatible Endpoints

1. Get Single Hadith

GET /api/hadeeths/one/?id={hadith_id}&language={language_code}

Description: Retrieve complete hadith details with translations, explanations, references, and categories.

Examples: http://127.0.0.1:8000/api/hadeeths/one?id=75455&language=bn http://127.0.0.1:8000/api/hadeeths/one?id=75614&language=en http://127.0.0.1:8000/api/hadeeths/one?id=1690&language=ar

2. List Hadeeths by Category

GET /api/hadeeths/list/?language={lang}&category_id={id}&page={page}&per_page={count}

Description: Get paginated list of hadeeths for a specific category.

Examples: http://127.0.0.1:8000/api/hadeeths/list?language=bn&category_id=1&page=1&per_page=20 http://127.0.0.1:8000/api/hadeeths/list?language=en&category_id=1&page=1&per_page=10

3. Get Root Categories

GET /api/categories/roots/?language={language_code}

Description: Retrieve all root-level categories with hadith counts.

Examples: http://127.0.0.1:8000/api/categories/roots?language=bn http://127.0.0.1:8000/api/categories/roots?language=en http://127.0.0.1:8000/api/categories/roots?language=ar

4. Get Available Languages

GET /api/languages

Description: List all supported languages with codes and native names.

Example: http://127.0.0.1:8000/api/languages
