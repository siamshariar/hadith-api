📋 Complete Hadith API URL List

Hierarchical API structure for Books and Categories with hadith data and translations

⚠️ Important: Hadith ID Range

Hadith database IDs range from 1590 to 2000

IDs 1, 2, 3... do not exist. Use IDs like 1590, 1591, etc.

📚 Books API Hierarchy

📚 Books → 📑 Chapters → 📖 Hadiths → 🌍 Translations
Books Flow: Home Page → Book Details → Chapters → Hadiths List → Individual Hadith → Language Translations

🏠 Books Home Page

GET /api/books
Get all books with chapters and hadith counts

📖 Books Data & Chapters

GET /api/books/{book}
Get specific book details + all chapters
GET /api/books/{book}/chapters
Get all chapters for a specific book

📜 Books Wise Chapters Hadith List

GET /api/books/{book}/chapters/{chapter}
Get hadiths for a specific chapter (paginated)

📝 Hadith & Hadith Language Wise Translations

GET /api/hadiths/{id}
Get specific hadith by database ID
GET /api/books/{book}/hadiths/{hadith_number}
Get specific hadith by book and hadith number
GET /api/hadiths/{id}/translations/{lang}
Get translation by hadith ID (en, bn, tr, ur)
GET /api/books/{book}/hadiths/{hadith_number}/translations/{lang}
Get translation by book and hadith number
