📚 Books API Hierarchy

📚 Books → 📑 Chapters → 📖 Hadiths → 🌍 Translations

🏠 Books Home Page

GET /api/books
Get all books with their chapters and hadith counts

📖 Book Details & Chapters

GET /api/books/{book}
Get specific book details + all chapters (book ID, code, or slug)
GET /api/books/{book}/chapters
Get all chapters for a specific book

📜 Chapter Hadiths

GET /api/books/{book}/chapters/{chapter}
Get hadiths for a specific chapter (paginated)

📝 Individual Hadiths

GET /api/hadiths/{id}
Get specific hadith by database ID
GET /api/books/{book}/hadiths/{hadith_number}
Get specific hadith by book and hadith number

🌍 Translations

GET /api/hadiths/{id}/translations/{lang}
Get translation by hadith ID (en, bn, tr, ur)
GET /api/books/{book}/hadiths/{hadith_number}/translations/{lang}
Get translation by book and hadith number

🏷️ Categories API Hierarchy

🏷️ Categories → 📖 Hadiths → 🌍 Translations

🏠 Categories Home Page

GET /api/categories
Get all categories with hierarchical structure

🏷️ Category Details

GET /api/categories/{category}
Get specific category details with subcategories and hadith count

📖 Category Hadiths

GET /api/categories/{category}/hadiths
Get hadiths for a specific category (paginated)

🌍 Translations (Same as Books)

GET /api/hadiths/{id}/translations/{lang}
Get translation by hadith ID (en, bn, tr, ur)
GET /api/books/{book}/hadiths/{hadith_number}/translations/{lang}
Get translation by book and hadith number

Level 📚 Books API 🏷️ Categories API Response Type
1. Home /api/books /api/categories List of all items
2. Details /api/books/{book} /api/categories/{category} Single item details
3. Sub-items /api/books/{book}/chapters Subcategories in details Child items list
4. Content /api/books/{book}/chapters/{chapter} /api/categories/{category}/hadiths Hadiths list (paginated)
5. Individual /api/hadiths/{id}
/api/books/{book}/hadiths/{num}		 Same as Books Single hadith
6. Translations /api/hadiths/{id}/translations/{lang}
/api/books/{book}/hadiths/{num}/translations/{lang}		 Same as Books Hadith + translation

📝 Arabic Text

حَدَّثَنَا الْحُمَيْدِيُّ عَبْدُ اللَّهِ بْنُ الزُّبَيْرِ ، قَالَ : حَدَّثَنَا سُفْيَانُ ، قَالَ : حَدَّثَنَا يَحْيَى بْنُ سَعِيدٍ الأَنْصَارِيُّ ، قَالَ : أَخْبَرَنِي مُحَمَّدُ بْنُ إِبْرَاهِيمَ التَّيْمِيُّ ، أَنَّهُ سَمِعَ عَلْقَمَةَ بْنَ وَقَّاصٍ اللَّيْثِيَّ يَقُولُ : سَمِعْتُ عُمَرَ بْنَ الْخَطَّابِ رَضِيَ اللَّهُ عَنْهُ ، يَقُولُ : سَمِعْتُ رَسُولَ اللَّهِ صَلَّى اللَّهُ عَلَيْهِ وَسَلَّمَ ، يَقُولُ : « إِنَّمَا الأَعْمَالُ بِالنِّيَّاتِ ، وَإِنَّمَا لِكُلِّ امْرِئٍ مَا نَوَى ، فَمَنْ كَانَتْ هِجْرَتُهُ إِلَى اللَّهِ وَرَسُولِهِ فَهِجْرَتُهُ إِلَى اللَّهِ وَرَسُولِهِ ، وَمَنْ كَانَتْ هِجْرَتُهُ لِدُنْيَا يُصِيبُهَا أَوِ امْرَأَةٍ يَنْكِحُهَا فَهِجْرَتُهُ إِلَى مَا هَاجَرَ إِلَيْهِ »

🌍 Available Translations

🇺🇸 English (en):
Narrated 'Umar bin Al-Khattab: I heard Allah's Messenger (ﷺ) saying, "The reward of deeds depends upon the intentions and every person will get the reward according to what he has intended. So whoever emigrated for worldly benefits or for a woman to marry, his emigration was for what he emigrated for."
🇧🇩 Bengali (bn):
উমর ইবনুল খাত্তাব (রাঃ) থেকে বর্ণিত: আমি আল্লাহর রাসূল (সাল্লাল্লাহু আলাইহি ওয়াসাল্লাম)-কে বলতে শুনেছি, "আমলসমূহ নিয়তের উপর নির্ভরশীল এবং প্রত্যেক ব্যক্তি তার নিয়ত অনুযায়ী প্রতিফল পাবে। যার হিজরত আল্লাহ ও তাঁর রাসূলের উদ্দেশ্যে, তার হিজরত আল্লাহ ও তাঁর রাসূলের উদ্দেশ্যে। আর যার হিজরত দুনিয়া লাভের জন্য অথবা কোন মহিলাকে বিবাহ করার জন্য, তার হিজরত সেই উদ্দেশ্যের জন্য যার জন্য সে হিজরত করেছে।"
