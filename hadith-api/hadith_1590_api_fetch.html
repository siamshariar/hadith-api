📝 cURL Examples

Fetch Hadith Data

Bash
curl -X GET "http://127.0.0.1:8000/api/hadiths/1590" \ -H "Accept: application/json"

Fetch English Translation

Bash

🐍 Python Examples

Fetch Hadith Data

Python
import requests # Fetch hadith data response = requests.get('http://127.0.0.1:8000/api/hadiths/1590') data = response.json() print(f"Hadith ID: {data['data']['id']}") print(f"Book: {data['data']['book']['name_en']}") print(f"Chapter: {data['data']['chapter']['name_en']}") print(f"Hadith Number: {data['data']['hadith_number']}") print(f"Arabic Text: {data['data']['arabic_text'][:100]}...")

Fetch Translation

Python
import requests # Fetch English translation response = requests.get('http://127.0.0.1:8000/api/hadiths/1590/translations/en') data = response.json() print(f"Translation: {data['data']['translation']['translation_text']}")

📱 JavaScript Examples

Fetch with Fetch API

JavaScript
// Fetch hadith data fetch('http://127.0.0.1:8000/api/hadiths/1590') .then(response => response.json()) .then(data => { console.log('Hadith:', data.data); console.log('Book:', data.data.book.name_en); console.log('Arabic Text:', data.data.arabic_text); }) .catch(error => console.error('Error:', error)); // Fetch translation fetch('http://127.0.0.1:8000/api/hadiths/1590/translations/en') .then(response => response.json()) .then(data => { console.log('Translation:', data.data.translation.translation_text); }) .catch(error => console.error('Error:', error));

⚡ PHP Examples

Fetch Hadith Data

PHP
<?php // Fetch hadith data $url = 'http://127.0.0.1:8000/api/hadiths/1590'; $response = file_get_contents($url); $data = json_decode($response, true); echo "Hadith ID: " . $data['data']['id'] . "\n"; echo "Book: " . $data['data']['book']['name_en'] . "\n"; echo "Chapter: " . $data['data']['chapter']['name_en'] . "\n"; echo "Hadith Number: " . $data['data']['hadith_number'] . "\n"; echo "Arabic Text: " . substr($data['data']['arabic_text'], 0, 100) . "...\n"; ?>
